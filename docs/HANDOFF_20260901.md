## THE INTAKE DESIGN (research complete, 104 findings, 0 failed verification)

Full output: workflow wf_e4f4bef6-84c. Verified: Marvel 1999 (PMID 9918487) re-checked
independently this session. NOTE: PubMed HTML hits a cookie wall; use
`https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=<PMID>&retmode=json`.

**The reframe:** this is a Best Possible Medication History plus a person-centred
assessment, not onboarding. NICE NG108 says more than one session is correct practice
and the same practitioner should carry continuity. So interruption is not a failure
mode to recover from — "a call that ends at medicine four of nine is Tuesday."

**Load-bearing evidence**
- Sternberg 1997 (PMID 9422833): open-ended rapport -> 2.5x more detail, and the effect
  persists into later unscripted turns. Response format is contagious. Therefore: NO
  slot-filling turn may execute before the open narrative completes.
- Marvel 1999 (PMID 9918487): clinicians redirect at 23.1s; patients allowed to finish
  take only 6 more seconds. This is a VAD parameter, not a prompt — long end-of-turn
  silence during narrative, tighter for slot-filling.
- AHRQ Tool 8 (brown bag): only by handling the containers do you learn how medicines
  are really taken. He can carry a phone to the medicine cabinet; he cannot carry a
  screen there and read it. **Voice is strictly superior here, not a compromise.**
- ISMP Canada BPMH guide already asks about "low vision or reading difficulties" as a
  barrier. The most important question for this house is in the standard instrument.
- Francis 2023 (PMID 37291672): aOR 1.11 per additional medication for a history
  deviation. A long list is riskier, not merely longer. Drives read-back rigour.
- Lechner 2019 (PMID 30851072): acquiescence bias — read-back must be built to catch
  errors, not to elicit a polite yes.

**Structure:** Call A meeting (~10 min, caregiver alone) / Call B medicines (bottles in
hand, time he picks) / Call C short and warm with her / Call D+ one hard question at a
time riding the daily check-in. Never combine B and C. Never put hard questions in A.

## THOMAS'S NOTES — NOT YET BUILT

1. **Trailing off.** Long pauses are normal in the elderly, especially as they sunset.
   If a sentence stops mid-way, Cura should offer a gentle check-in — "finding a word?",
   "oh, did I lose you there?" — rather than treating silence as end-of-turn. Some voice
   monitoring already exists; wire it to this. Note this INTERACTS with the Marvel
   finding: long silence thresholds during narrative must not read as abandonment.
2. **Edge-case testing in the Agent Army mix?** Open question. His system-breaker
   instinct went straight to medication schedules that are not daily: **PRN / "as needed"**
   and **weekly** dosing both need representation and tracking. Current model has two
   slots (morning/evening) and no concept of either.
3. **Phone sensor package** is an option already; **video call** ability worth exploring —
   other companion and business agents ship it.
4. **Write conversations as extemporaneous if/then, not scripts.** Claude is the backend
   at least initially, so the artifact should be system-prompt and decision guidance tuned
   to Claude, not a dialogue tree. This is a directive about the FORM of the deliverable.
